# Dokumentácia konferenčného systému

Dokumentácia je po slovensky. Názvy rout, komponentov, dátových polí a kódu sú po anglicky.

## Lokálny vizuálny prototyp

[Stav, dizajn a overenie prototypu](frontend-prototyp.md) – 33 obrazoviek podľa analýzy a dva pomocné zoznamy, so vzorovými údajmi a preklikávaním. Spustenie je v [README aplikácie](../README.md). Backend zatiaľ nie je zapojený.

## Aktuálne podklady

- [Analýza frontendu a obrazoviek](frontend-analyza.md) – pracovný návrh na revíziu, vrátane navigácie, oprávnení, stavov, otvorených otázok a navrhovanej štruktúry budúceho frontendu.
- [Zdrojová analýza v Google Docs](https://docs.google.com/document/d/1Viv6vJhFhKZsgyNeoKLImNAMIpUWBhtpL-qs3OFqeQM/edit) – obsahuje pôvodné úvahy tímu aj neskoršiu odpoveď zákazníka. Pri rozpore vychádzame z odpovede zákazníka.

## Navrhovaný ďalší postup dokumentácie

Po revízii rozpracovať podľa potreby: dátový model, oprávnenia, pravidlá stavov, kontrakty s backendom, dizajnové pravidlá a akceptačné scenáre. Tieto dokumenty zatiaľ nevznikli; ich obsah ani technológie nie sú týmto návrhom schválené.

Pri každom rozhodnutí uviesť jeho stav, zdroj a prípadnú otvorenú otázku. Funkcie plánované v dokumentácii neznamenajú implementovanú funkcionalitu.
